# 成品拆解与图片构图

## 公开成品里的图片摆法

- **《Preparing to Fail》** 第 1、23 页以同一张倾斜货船照片满版开场和收尾。中间多用纯色和简图，第 13 页在标题下并列两幅界面，观众可以直接比对状态。可借用「让开场意象成为收尾的回答」和「对照时固定图框与位置」两种结构。[TED 团队成品](https://www.slideshare.net/slideshow/all-handspreparingtofail/37005729)
- **Leica Store 旅行摄影讲座** 第 6 页整页只放庭园照。第 16、20 页用一张竖幅主图和两张叠放的横幅小图组成一组。第 17、19、21–24 页的城市例图将大照片放在标题下方，留出统一的页边。可借用「单图停顿」「主图定视线，小图补细节」「同一框架连播可比案例」。[原作者逐页发布的讲座](https://www.travelisbeautiful.com/ricks-blog/2019/11/16/presentation-on-travel-photography-at-the-leica-store)
- **纽约市 DDC Design-Build Forum** 按 PDF 页码计，第 9 页用等间距网格展示项目广度，第 22 页将人物现场照裁成上方横带，第 26 页让施工人员的抠图落在白底上，第 42–43 页将大的鸟瞰图置于上方、两幅近视角图放在下方。第 44–49 页又以相近的平面图视角强调各方案中的变化。可借用「图带定场」「主体露出」「总览带细节」和「固定画幅只换重点」。[NYC DDC 论坛成品](https://www.nyc.gov/assets/ddc/downloads/mwbe/presentations/DB%20Forum-2022.03.24.pdf)

## 先定叙事任务，再定图框

| 适合的场景 | 摆法 | 制作要点 |
| --- | --- | --- |
| 开场、转场或需要一拍停顿 | **整页照片** | 让主体和视线占画面。纯图可承接一句口播。必须上字时，把文字放在低细节区，按需加局部暗罩。 |
| 让观众进入场景，正文仍需独立阅读 | **上方横带或底部图带** | 挑横向有动作的信息区，如街面、货架、车窗或地平线。下方图带可作为延续场景的视觉基座。图与文之间留出清楚的边界。 |
| 一眼看懂一件器物、一张档案或一个结果 | **居中大图并留出页边** | 用上方短题和图下简注形成轴线。保留原图比例，空白给轮廓和细节腾位置。 |
| 对象轮廓本身能传递信息 | **抠出的主体融入画布** | 可让产品、人物动作或手稿跨过色面边界。保留关键身体部位、接触边或工作姿态，检查透明边缘和背景反差。 |
| 既需要交代位置，又要看清小细节 | **总览和局部特写** | 可以上大下小，也可把一幅放大图嵌进总览的空区。用相同编号、轻圈选或连接线标明局部来自哪里。图注标出局部的意义。 |
| 多张照片共同讲一件事 | **一张主图带小图** | 主图先让人看懂人物、环境或结果。小图补充过程、纹理或另一视角。用共用边、统一间距和相关裁切把它们连起来。 |
| 展示范围或并列证据 | **等权组图** | 用对齐的网格、连拍条或同尺寸的纵向三联。每格应回答同一个问题，图的能见信息比铺满格数更重要。 |
| 前后状态、步骤变化、同类案例 | **固定视点连续出图** | 让关键部件在相邻页待在同一位置，改变状态、局部或注释。在关键变化处再用特写。 |
| 开场提出一个可回收的意象 | **首尾回图** | 结尾可回到开场原图，也可改为同对象的近景、变化后状态或更宽的现场。让口播或短标题给出新含义。 |

## 整段演示一起排

先在页序图中写明每幅图负责什么，如定场、举证、比较或收束。让图幅和观看距离跟着讲述变化。比如讲街区可以用「满版街景 → 上图下文说明范围 → 现场图加两处细节 → 等大图片比较实施前后 → 回到开场街景」。如整段是并列案例，用统一图框帮助逐项读，把变化留给段落开头与转折。

拿到图片后在真实图框中试裁。分别看页间缩略图和单页放映尺寸。页间检查是否反复出现相同的左右分栏、图的大小有没有随任务变化。单页检查图中人物、标志和可核对的证据是否留下，配图与图注是否能直接对应。模板固定了某个图框时，可以在模板允许的开场页、比较页和过渡页安排变化。
