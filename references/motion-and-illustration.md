# 情景动效、叙事插图和风格变化

<a id="motion"></a>
## 写一句动作，再排这一拍

在逐页大纲里同时记录「翻页方式」和「页内首次出现的内容」。现场讲述默认由讲者点按翻页，常规页用短淡化。观众首先要读的标题与背景通常从首帧可见。确有叙事目的时让主图、关键词或证据稍后入场。把关键转折设为点击触发，相关动作可以随前项或按短延迟完成。数字、字幕和论证出现后要留足阅读时间。

| 内容需要 | 默认选择 | 建议时长与触发 |
| --- | --- | --- |
| 普通翻页，视角与话题延续 | 短淡化，让标题和正文很快可读 | 翻页 200–350 ms，由讲者点按 |
| 普通页入场，图或关键词是首个讲点 | 对象淡入，题目先在场，只揭示一组 | 180–300 ms，自动接在转场后或随台词点击 |
| 前后对照、两张等重要的图 | 同步淡入。需要先问后揭晓时分两步 | 单组约 200–300 ms。给问答留一拍 |
| 时间、路径或按步骤讲解 | 按实际阅读方向擦除一段，标签随各段出现 | 每段 200–350 ms，按讲点推进 |
| 相邻页在讲同一物件的连续变化 | 保持对象对应并使用 Morph。播放端只支持普通切换时用淡化配两帧 | 350–650 ms，由讲者点按 |
| 新章节或明显转折 | 选择与画面动作对应的短转场，如分割、揭幕或响亮的字符入场 | 转场约 350–650 ms。特殊动作围绕台词调整 |
| 查值密集、快速连续比较或安静的长引文 | 一次显示完整内容，必要时仅做短切或淡化 | 给阅读留停顿，不遮挡当下信息 |

对三页以上的默认放映稿，至少做出常规翻页和一处有内容理由的对象入场。有多个章节时，逐章检查普通内容页的首次出现状态，优先在有主图或首个讲点的代表页上做一次轻量入场。资料表、长引文和需要整页同时比较的图表可以直接完整显示。在实际 PPTX 里保存动画，一次点击尽量完成一个讲点。用户指定静态或减少动效时，保留内容完整、可读的结束画面。转场和对象入场的时序分别核对。[PowerPoint 转场与动画](https://support.microsoft.com/en-us/powerpoint/training/design-in-powerpoint)

| 情景 | 开始和完成画面 | PPT 实现 |
| --- | --- | --- |
| 「睁开眼」 | 近黑的前景让位，床头或街景出现 | 以黑遮罩做分割退出或上下两片向外撤。保留约半秒至一秒作检查起点，实际按配音停顿调整。背景先就位，重要文字在揭幕后进入。 |
| 标题突然警醒 | 题目从无到完整，读者听到词组重音 | 单文本框用按字符触发，或把单字置于相同基线上做短落位。约 45–85 ms 的连续起点和短淡入、轻位移或单次轻弹是起点。按词组断句，保留完整可读的结束画面。 |
| 手机来了新消息 | 状态栏与聊天容器早已在场，新气泡与说话人同步出现 | 气泡、时间和角色名分层。按台词逐条淡入或短滑入，避免整台手机跟着晃。第二次点按只引出下一个讲点。 |
| 红灯转绿 | 灯壳不动，红灯熄灭，绿灯点亮 | 灯壳、熄灭镜片、发光层分别放置。用短淡出或淡入切换状态。字幕说明「等待／通行」，让颜色和文字互相补足。 |

**参考原稿**。《你被算法安排的一天》第 1 页在同一标题对象上配置了两段按字符进入，再接字幕。第 2 页有全屏前景遮罩退出及音频播放。可以把这些做法迁移到自己的开场。原稿中按字符播放的设计可以用淡入、短位移或轻弹重现，按新演示的台词与节奏选择。

**落地与验证**。交付 PPTX 优先使用原生对象动画和可编辑文字。Morph 可用于相邻页面共享物件的转场，先检查播放端支持；同页逐字和按台词提示可使用动画窗格的触发及文本单元设置。用实际放映核对点击次数、首帧、最终帧、字序、叠层和媒体音量。导出为图片或 PDF 时选择揭示完成的画面。 [PowerPoint 按字符动画](https://learn.microsoft.com/en-us/office/vba/api/powerpoint.sequence.converttotextuniteffect) · [Morph 转场](https://support.microsoft.com/en-us/powerpoint/morph-transition-tips-and-tricks)

<a id="props"></a>
## 用代码绘制精致圆润的道具

先明确物件在故事里做什么，再用真实照片、界面或原型确定结构。手机外壳、提示弹窗、交通信号、单物件和流程默认用代码画。PPT 编辑或动画优先用原生形状；需要精细轮廓和材质时用独立 SVG，兼容性需要时导出高分辨率 PNG。SVG 用基本图元、路径、渐变和透明度，可以直接以文本编写。照片类证据用原图，叙事道具按需标注为示意。

1. **先定比例和轮廓**。在统一画布里对齐中心、屏幕边距和镜片间距，先画外壳、内凹区和主要结构。圆角按对象角色取两到三级，例如外壳 24、内屏 18、气泡 9。套叠边界保持等间距时，内圆角半径约为外半径减内缩距离。
2. **统一描边与光线**。同类细节共享一档线宽，主轮廓可稍重。线条用圆端和圆连接，转弯用平滑路径。材质主要用同色系的深浅层次，保持高光来自同一方向。柔影贴近物件底部，亮点落在玻璃、金属边或点亮镜片上。
3. **按层组织**。把外壳和静态装饰、可读标签、交互状态分别分组。手机保留状态栏和可读消息，信号灯保留遮光檐和熄灭镜片。屏幕文字或需要切换的光层留作独立原生对象。SVG 可用分组、渐变和圆角路径，避开对外部字体、图片和滤镜的依赖。
4. **在真实图位验收**。检查远看能否辨认轮廓，近看圆角是否一致、光影是否贴合物体、关键字能否看清。缩小后会糊的装饰先减掉。要演示状态变化时分开预览开始和结束两帧。

- **手机**。观察边框厚度、屏幕圆角、摄像头区域、状态栏、对话气泡的内边距。给玻璃和金属轻微反光，给手机一个接触阴影。屏幕里的角色、时间、关键短句尽量保持可读。斜拍会影响文字叠加时使用近正面角度，或把重要内容另行局部放大。
- **红绿灯**。用灯壳、遮光檐、镜片的凸面高光和暗部建立立体感。打开的镜片较亮，熄灭的灯仍能看到镜片，光晕局部控制。按地域和场景核对灯位与状态。一个简图用于识别状态，一张现场照片用于陈述地点或事件。
- **其他题材**。从物件轮廓、材质、尺度、连接或操作方式选最有识别力的细节。例如地铁闸机应看得出刷卡区和通行方向，便利店自提柜应看得出门格、取货动作与人手的相对尺寸。

[手机与信号灯 SVG 源文件](../assets/code-drawn-props.svg) 展示了嵌套圆角、轻微渐变、镜片及可独立替换的状态层。可在浏览器直接打开，再按当前题材重画。

## 让页型随叙事变化

排完大纲后挑出听众最该记住的几个节拍，分别给它们合适的画面结构。宽图或沉浸场景用于入场，亮底和稳定网格承载数据，单个大字或大数用于转折，关系页可以用并排图、双栏或共享行头。章节可以换冷暖或底色，保留对齐线、正文字体、语义或反复出现的物件来串联整篇。相邻的同一版式通常用于需要横向比较的系列页。

做新题目前挑两到三个质量好的案例按用途拆解。看完整预览中的开场、信息密集页、图文页和过渡页，记录「这个设计解决了什么问题、是否适合当前素材」。以下是相近的参考入口，按任务选读并遵循素材的许可条款。

- **杂志感与图文变化**。研究同一份里横幅照片、留白、列宽和字号跨度的变化。适合人物、行业观察和社会案例。[Editorial Magazine](https://slidesgo.com/theme/editorial-magazine)
- **作品集的裁图与留白**。研究图片位置随长短、横竖和阅读方向变化时如何维持整体关系。[Editorial Design Portfolio](https://slidesgo.com/theme/editorial-design-portfolio)
- **科技主题的插画语法**。研究一套角度、材质或视角怎样贯穿多个应用页。与当前原稿做对照再决定是否要采用等距风格。[Digital Magazine Pitch Deck](https://slidesgo.com/theme/digital-magazine-pitch-deck)
